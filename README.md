# Hi, I'm 周漢璋 (Han-Chang Chou) 👋

**Senior AI Engineer @ WNC** · M.S., National Yang Ming Chiao Tung University (NYCU)

I turn Wi-Fi Channel State Information (CSI) into signals about people: who's in the room, what they're doing, where they are, and how they're breathing.

- 🏢 Senior AI Engineer at **Wistron NeWeb Corporation (WNC)**, working on Wi-Fi sensing through an industry–academia collaboration with NYCU
- 🎓 M.S. graduate of NYCU, Green Computing and Embedded Systems Lab, advised by **Prof. Shiao-Li Tsao (曹孝櫟)**

## 🔬 What I work on

- **Occupancy & presence detection** — robust in-room / bathroom presence sensing, including the awkward edge cases
- **Human activity recognition** — classifying motion and activity from CSI time series
- **Localization** — device-free indoor positioning with Wi-Fi
- **Cardiopulmonary sensing** — contactless respiration / heart-rate (BPM) estimation
- **Large Wi-Fi signal models** — exploring multimodal foundation-model approaches for Wi-Fi sensing

## 🛠️ How I build

- **Signal processing** — CSI denoising, spectral anomaly detection, multi-dimensional CSI visualization
- **Model development** — training pipelines, data augmentation (time warping, amplitude scaling/shift), post-processing with state machines for stable predictions
- **Evaluation & diagnosis** — performance evaluation frameworks and embedding-space retrieval for diagnosing model errors
- **Deployment** — ONNX conversion and edge-ready inference
- **Data collection** — PicoScenes-based CSI capture setups and experiment replication
